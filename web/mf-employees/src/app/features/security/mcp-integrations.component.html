Conectar una app MCP personalizada

  1. Publicá una URL estable con HTTPS o usá un túnel seguro aprobado. Un endpoint local o privado no es accesible desde ChatGPT cloud.
  2. En Keycloak, creá un cliente OAuth estático para ChatGPT y registrá exactamente la URI de redirección que ChatGPT te muestre. No supongas una callback.
  3. Registrá aquí el mismo clientId y los alcances mínimos. El ID debe corresponder al cliente OAuth de Keycloak.
  4. En la configuración de apps MCP de ChatGPT, pegá el endpoint mostrado (termina en /mcp) y elegí OAuth.
  5. Iniciá sesión y aceptá el consentimiento. Revisá la lista de herramientas permitidas y probá primero una consulta de solo lectura.

La disponibilidad puede depender del plan, workspace y políticas de ChatGPT. Esta pantalla no verifica una sesión real de ChatGPT.

Secretos: el client secret se configura en Keycloak/ChatGPT cuando corresponda. AutoNexus nunca lo solicita, guarda ni vuelve a mostrar.
