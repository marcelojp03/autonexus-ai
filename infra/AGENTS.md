# Infraestructura
Leer instrucciones raíz. Configurar Keycloak, RabbitMQ, PostgreSQL con bases/credenciales por propietario, MongoDB, DynamoDB y n8n según el alcance. Amazon S3 es el almacenamiento elegido. Crear ejemplos sin secretos y documentar comandos verificados. No desplegar ni publicar recursos externos por el solo hecho de generar esta estructura.
