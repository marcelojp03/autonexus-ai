## CU02. Administrar roles y permisos

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU02. Administrar roles y permisos |
| Propósito | Controlar las funcionalidades y operaciones que puede ejecutar cada empleado del taller. |
| Resumen | El administrador configura roles y permisos asociados a los diferentes módulos de AutoNexus AI. |
| Actores | Administrador, Keycloak. |
| Actor iniciador | Administrador. |
| Precondición | El administrador tiene una sesión activa y permisos para gestionar accesos. |
| Flujo principal | **1.** El administrador accede a la sección de seguridad. **2.** Consulta los roles existentes. **3.** Selecciona un rol para modificarlo o registra uno nuevo. **4.** Define permisos de consulta, creación, modificación y operaciones especiales. **5.** Asigna o retira el rol a los empleados correspondientes. **6.** El sistema valida las restricciones de seguridad. **7.** Actualiza la configuración autorizada en Keycloak y en las políticas de acceso de la plataforma. **8.** Registra la operación en la auditoría. |
| Postcondición | Los roles y permisos quedan actualizados y se aplican a las operaciones posteriores. |
| Excepción | Rol duplicado; permisos incompatibles; intento de asignar permisos superiores a los del administrador; error de comunicación con Keycloak; modificación que dejaría al sistema sin un administrador autorizado. |
