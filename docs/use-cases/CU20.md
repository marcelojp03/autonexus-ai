## CU20. Registrar gastos operativos

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU20. Registrar gastos operativos |
| Propósito | Llevar un control de los gastos relacionados con el funcionamiento del taller mecánico. |
| Resumen | El responsable financiero registra gastos como servicios básicos, herramientas, mantenimiento de equipos y otros costos administrativos autorizados. |
| Actores | Responsable financiero, Administrador. |
| Actor iniciador | Responsable financiero. |
| Precondición | El usuario está autenticado y tiene permisos para registrar gastos. Existen categorías de gastos configuradas. |
| Flujo principal | **1.** El usuario ingresa al módulo de gastos. **2.** Selecciona registrar gasto. **3.** Introduce descripción, categoría, fecha, importe y medio de pago. **4.** Adjunta un respaldo documental cuando corresponda. **5.** El sistema valida los datos y la posible duplicidad del registro. **6.** El usuario confirma la operación. **7.** El sistema almacena el gasto y registra su responsable. **8.** Actualiza la información disponible para los reportes financieros. |
| Postcondición | El gasto queda registrado y puede consultarse en los informes administrativos. |
| Excepción | Importe inválido; información incompleta; gasto duplicado; categoría inexistente; documento no permitido; falta de permisos; error de persistencia. |
