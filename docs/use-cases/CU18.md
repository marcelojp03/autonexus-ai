## CU18. Registrar entrega de vehículo

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU18. Registrar entrega de vehículo |
| Propósito | Formalizar la devolución del vehículo al cliente después de completar el servicio y cumplir las condiciones administrativas aplicables. |
| Resumen | La recepcionista registra la fecha, responsable y condiciones de entrega del vehículo, cerrando su proceso de atención. |
| Actores | Recepcionista, Jefe de taller. |
| Actor iniciador | Recepcionista. |
| Precondición | La orden está técnicamente finalizada y cumple las condiciones de entrega, incluidos los requisitos de cobro o autorización de crédito que correspondan. |
| Flujo principal | **1.** La recepcionista busca la orden finalizada. **2.** El sistema muestra los servicios realizados y el estado administrativo. **3.** Verifica la autorización de entrega. **4.** Confirma los datos del vehículo y del receptor. **5.** Registra fecha, hora, observaciones finales y evidencia de entrega. **6.** Confirma la operación. **7.** El sistema actualiza el estado del vehículo y de la orden a entregado. **8.** La intervención queda incorporada al historial del vehículo. |
| Postcondición | La entrega queda registrada y se completa el ciclo de atención del servicio. |
| Excepción | Orden no finalizada; cobro pendiente sin autorización; persona receptora no autorizada; vehículo ya entregado; datos incompletos; error al guardar. |
