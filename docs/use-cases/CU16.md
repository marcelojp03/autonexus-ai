## CU16. Registrar ejecución, avances y evidencias

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU16. Registrar ejecución, avances y evidencias |
| Propósito | Documentar el trabajo efectuado por el mecánico y mantener actualizado el seguimiento de cada orden de servicio. |
| Resumen | El mecánico registra actividades realizadas, tiempos de trabajo, observaciones y fotografías que evidencian el estado de la reparación. |
| Actores | Mecánico, Jefe de taller, Amazon S3. |
| Actor iniciador | Mecánico. |
| Precondición | Existe una orden confirmada y asignada al mecánico. El empleado dispone de permisos para registrar avances. |
| Flujo principal | **1.** El mecánico consulta sus órdenes asignadas. **2.** Selecciona la orden que está ejecutando. **3.** Registra el inicio de la actividad. **4.** Introduce observaciones, tareas realizadas y tiempo empleado. **5.** Adjunta fotografías o videos permitidos como evidencia. **6.** El sistema valida los datos y archivos. **7.** Con conectividad, los archivos se cargan de forma segura en Amazon S3 y se registran sus referencias; sin conexión, quedan pendientes de sincronización. **8.** El mecánico guarda el avance y el sistema actualiza el progreso de la orden. |
| Postcondición | Los avances quedan registrados y las evidencias almacenadas o pendientes de carga, según la conectividad. |
| Excepción | Orden no asignada; actividad duplicada; archivo no permitido; archivo demasiado grande; fallo de carga a S3; almacenamiento local insuficiente; conflicto de versiones; falta de autorización. Los datos offline permanecen pendientes hasta que se complete la sincronización. |
