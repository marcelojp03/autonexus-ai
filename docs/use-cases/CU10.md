## CU10. Gestionar citas de servicio

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU10. Gestionar citas de servicio |
| Propósito | Organizar las solicitudes de atención de vehículos mediante un calendario de citas. |
| Resumen | La recepcionista registra, modifica, reprograma o cancela citas para los servicios ofrecidos por el taller. |
| Actores | Recepcionista, Jefe de taller. |
| Actor iniciador | Recepcionista. |
| Precondición | El cliente y el vehículo están registrados. El usuario dispone de permisos para administrar citas. |
| Flujo principal | **1.** La recepcionista ingresa a la agenda de citas. **2.** Selecciona registrar una nueva cita. **3.** Busca al cliente y su vehículo. **4.** Selecciona el servicio solicitado. **5.** Introduce la fecha, hora y observaciones. **6.** El sistema comprueba la capacidad y disponibilidad del taller. **7.** La recepcionista confirma la programación. **8.** El sistema registra la cita y actualiza el calendario. |
| Postcondición | La cita queda registrada y disponible para su seguimiento. |
| Excepción | Cliente o vehículo inexistente; horario no disponible; cita duplicada; servicio inactivo; falta de permisos; error de comunicación. Para reprogramar se repite la validación de disponibilidad. Para cancelar se registra el motivo y se liberan las reservas asociadas. Una cita creada offline permanece provisional hasta recibir confirmación del servidor. |
