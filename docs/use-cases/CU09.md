## CU09. Gestionar catálogo de servicios automotrices

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU09. Gestionar catálogo de servicios automotrices |
| Propósito | Definir los trabajos de mecánica ofrecidos por el taller para estandarizar su gestión. |
| Resumen | El administrador registra los tipos de servicio que ofrece el taller, sus descripciones, duración estimada y tarifa referencial. |
| Actores | Administrador, Jefe de taller. |
| Actor iniciador | Administrador. |
| Precondición | El administrador está autenticado y tiene permisos para modificar el catálogo de servicios. |
| Flujo principal | **1.** El usuario ingresa al catálogo de servicios. **2.** Consulta los servicios existentes. **3.** Selecciona crear o modificar un servicio. **4.** Ingresa nombre, descripción, categoría, duración estimada y tarifa referencial de mano de obra. **5.** El sistema verifica la consistencia de los datos. **6.** El usuario confirma el registro. **7.** El sistema guarda la información y la habilita para citas y cotizaciones. |
| Postcondición | El servicio queda registrado o actualizado en el catálogo. |
| Excepción | Servicio duplicado; información incompleta; duración o tarifa inválida; falta de permisos; error de persistencia. Los servicios utilizados anteriormente no se eliminan físicamente; pueden desactivarse. |
