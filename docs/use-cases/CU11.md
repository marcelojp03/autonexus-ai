## CU11. Recepcionar e inspeccionar vehículo

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU11. Recepcionar e inspeccionar vehículo |
| Propósito | Registrar la llegada del vehículo y documentar sus condiciones iniciales antes de realizar un trabajo mecánico. |
| Resumen | La recepcionista o el mecánico realiza la recepción del vehículo, registra el motivo de consulta y documenta observaciones preliminares. |
| Actores | Recepcionista, Mecánico. |
| Actor iniciador | Recepcionista. |
| Precondición | El vehículo y el cliente están registrados. Existe una cita o se ha autorizado una recepción sin cita previa. |
| Flujo principal | **1.** El usuario busca la cita o el vehículo. **2.** Selecciona iniciar recepción. **3.** Verifica los datos del vehículo. **4.** Registra kilometraje, motivo de consulta, síntomas reportados y condiciones visibles. **5.** Puede adjuntar fotografías o realizar una inspección visual asistida por IA. **6.** El sistema valida los datos requeridos. **7.** El usuario confirma la recepción. **8.** El sistema guarda el registro y habilita la creación de la orden de trabajo. |
| Postcondición | La recepción y las condiciones iniciales del vehículo quedan documentadas. |
| Excepción | Vehículo incorrecto; información incompleta; recepción previamente registrada; falta de permisos; fotografía inválida; error al almacenar evidencias. Las imágenes pendientes de una inspección offline se guardan localmente hasta sincronizarse con Amazon S3. |
