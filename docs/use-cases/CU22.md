## CU22. Realizar inspección visual mediante IA local

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU22. Realizar inspección visual mediante IA local |
| Propósito | Facilitar la identificación preliminar de anomalías visuales en vehículos mediante modelos de inteligencia artificial ejecutados directamente en el dispositivo. |
| Resumen | El mecánico captura o selecciona una imagen del vehículo. El sistema utiliza un modelo local de deep learning para analizarla sin requerir conexión a internet. |
| Actores | Mecánico, Jefe de taller. |
| Actor iniciador | Mecánico. |
| Precondición | El usuario está autorizado para realizar inspecciones, el modelo de IA está instalado o descargado y el dispositivo dispone de los recursos necesarios. |
| Flujo principal | **1.** El mecánico abre el módulo de inspección inteligente. **2.** Selecciona un vehículo o una orden de trabajo. **3.** Captura una fotografía o selecciona una imagen existente. **4.** El sistema verifica que el archivo cumpla los requisitos de entrada del modelo. **5.** Ejecuta el modelo local utilizando TensorFlow.js en web o LiteRT en móvil. **6.** El sistema presenta las posibles anomalías identificadas y sus niveles de confianza. **7.** El mecánico revisa los resultados y registra su interpretación. **8.** El sistema guarda la inspección localmente o la asocia con la orden. **9.** Si está offline, la información permanece pendiente de sincronización. |
| Postcondición | Se registra una inspección asistida por IA local, con sus resultados, versión del modelo y validación del mecánico. |
| Excepción | Modelo no disponible; formato de imagen incorrecto; calidad insuficiente; recursos del dispositivo insuficientes; inferencia fallida; confianza demasiado baja; falta de almacenamiento. El sistema debe permitir registrar una inspección manual si falla la IA. |
