## CU14. Registrar aprobación o rechazo de cotización

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU14. Registrar aprobación o rechazo de cotización |
| Propósito | Documentar la decisión del cliente respecto al costo y las condiciones de los servicios propuestos. |
| Resumen | La recepcionista o responsable financiero registra si el cliente acepta o rechaza la cotización. |
| Actores | Recepcionista, Responsable financiero. |
| Actor iniciador | Recepcionista. |
| Precondición | Existe una cotización pendiente de aprobación, vinculada a una orden de trabajo. |
| Flujo principal | **1.** El usuario busca la cotización correspondiente. **2.** El sistema muestra los servicios, costos y condiciones. **3.** El usuario comunica la cotización al cliente. **4.** Recibe su aceptación o rechazo mediante un mecanismo autorizado. **5.** Registra la decisión, fecha y evidencia disponible de la autorización. **6.** El sistema verifica que la cotización siga vigente. **7.** El usuario confirma el registro. **8.** El sistema actualiza el estado de la cotización y de la orden relacionada. |
| Postcondición | La cotización queda aprobada o rechazada, conservando evidencia de la decisión. |
| Excepción | Cotización expirada o modificada; falta de evidencia de autorización; cotización ya procesada; cambio de precios; error de persistencia. Si el cliente rechaza, la orden no puede avanzar a ejecución y queda pendiente de revisión o cancelación. |
