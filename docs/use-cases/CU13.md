## CU13. Elaborar cotización de servicio

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU13. Elaborar cotización de servicio |
| Propósito | Calcular y documentar el costo estimado de los servicios automotrices solicitados por un cliente. |
| Resumen | El responsable financiero elabora una cotización a partir de una orden de trabajo, considerando los servicios y sus tarifas correspondientes. |
| Actores | Responsable financiero, Recepcionista, Jefe de taller. |
| Actor iniciador | Responsable financiero. |
| Precondición | Existe una orden de trabajo registrada y el usuario tiene permisos para elaborar cotizaciones. |
| Flujo principal | **1.** El responsable financiero accede al módulo de cotizaciones. **2.** Selecciona una orden de trabajo pendiente. **3.** El sistema recupera los servicios solicitados. **4.** El usuario establece las tarifas de mano de obra, cantidades de servicio y ajustes autorizados. **5.** El sistema calcula subtotales, descuentos autorizados y el total estimado. **6.** El usuario revisa la cotización. **7.** Confirma su creación. **8.** El sistema almacena la cotización y la vincula con la orden de trabajo. |
| Postcondición | La cotización queda registrada con estado pendiente de aprobación. |
| Excepción | Orden inexistente; servicio no válido; importes incorrectos; falta de autorización para descuentos; error de cálculo o persistencia; cotización previamente aprobada. Los cambios posteriores a la aprobación requerirán una nueva versión de la cotización. |
