## CU26. Generar reportes inteligentes

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU26. Generar reportes inteligentes |
| Propósito | Elaborar reportes empresariales con indicadores cuantitativos e interpretaciones generadas mediante inteligencia artificial. |
| Resumen | El administrador selecciona un período y tipo de reporte. La plataforma recopila información de los módulos empresariales y genera un documento que contiene resultados, gráficos e interpretaciones. |
| Actores | Administrador, Jefe de taller, Responsable financiero. |
| Actor iniciador | Administrador. |
| Precondición | El usuario está autorizado, existe información suficiente para el reporte y el servicio de generación está disponible. |
| Flujo principal | **1.** El administrador ingresa al módulo de reportes. **2.** Selecciona el tipo de reporte: operativo, financiero o productividad del personal. **3.** Define período, filtros e indicadores. **4.** El sistema consulta la información correspondiente mediante las APIs empresariales. **5.** Calcula y valida las métricas obtenidas. **6.** El componente de IA genera una explicación narrativa de los resultados. **7.** El sistema prepara tablas, gráficos y conclusiones, distinguiendo datos de interpretaciones. **8.** El administrador revisa el reporte. **9.** Puede exportarlo en PDF u otro formato habilitado. |
| Postcondición | Se genera un reporte consultable o exportable, con sus indicadores y explicaciones asociadas. |
| Excepción | Información insuficiente; errores en cálculos; servicio de IA no disponible; datos contradictorios; fallo de generación; exportación incorrecta; falta de permisos. Si falla la IA, el sistema puede generar un reporte convencional sin interpretación automática. |
