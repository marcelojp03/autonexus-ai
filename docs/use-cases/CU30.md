## CU30. Solicitar operaciones empresariales mediante MCP

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU30. Solicitar operaciones empresariales mediante MCP |
| Propósito | Permitir que aplicaciones de IA externas compatibles con MCP soliciten acciones controladas dentro de AutoNexus AI sin acceder directamente a su lógica interna. |
| Resumen | Una aplicación externa invoca una herramienta MCP que representa una operación de negocio permitida, como solicitar una cita. |
| Actores | Aplicación de IA externa compatible con MCP. |
| Actor iniciador | Aplicación de IA externa compatible con MCP. |
| Precondición | El cliente dispone de autorización para la herramienta solicitada, existe un contexto de identidad válido y la operación está habilitada para integraciones externas. |
| Flujo principal | **1.** El cliente MCP consulta las herramientas de escritura disponibles. **2.** Selecciona una herramienta, por ejemplo `solicitar_cita`. **3.** Proporciona los argumentos requeridos. **4.** El servidor MCP autentica la solicitud y verifica los permisos específicos. **5.** Valida los datos y determina si es necesaria la confirmación de una persona autorizada. **6.** Cuando corresponde, solicita dicha confirmación antes de ejecutar la operación. **7.** Invoca la API empresarial correspondiente. **8.** El microservicio ejecuta sus validaciones y reglas de negocio. **9.** El servidor MCP devuelve el resultado y registra la operación en auditoría. |
| Postcondición | La operación queda realizada, rechazada o pendiente de confirmación, según el resultado de las validaciones y reglas del negocio. |
| Excepción | Permisos insuficientes; falta de confirmación; solicitud duplicada; operación no habilitada; datos inválidos; conflicto de disponibilidad; fallo transaccional; error de comunicación con el microservicio. Las herramientas MCP no podrán omitir las reglas de negocio ni los mecanismos de confirmación obligatorios. |
