## CU05. Consultar agenda de trabajos asignados

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU05. Consultar agenda de trabajos asignados |
| Propósito | Permitir que los mecánicos conozcan los servicios que deben realizar, sus horarios y prioridades. |
| Resumen | El mecánico consulta sus órdenes de trabajo asignadas desde la aplicación web o móvil. |
| Actores | Mecánico, Jefe de taller. |
| Actor iniciador | Mecánico. |
| Precondición | El empleado está autenticado y dispone de permisos para consultar las órdenes correspondientes. |
| Flujo principal | **1.** El mecánico abre la sección de trabajos asignados. **2.** El sistema identifica al empleado autenticado. **3.** Recupera los trabajos autorizados asociados al mecánico. **4.** Muestra las órdenes, vehículos, horarios, prioridades y estados. **5.** El mecánico selecciona una orden. **6.** El sistema presenta los detalles del servicio y las observaciones registradas. |
| Postcondición | El mecánico obtiene la información necesaria para organizar sus actividades sin modificar los datos de las órdenes. |
| Excepción | No existen trabajos asignados; orden cancelada; asignación modificada; falta de permisos; conexión no disponible. En modo offline solo se muestran los datos sincronizados previamente, indicando cuándo fueron actualizados. |
