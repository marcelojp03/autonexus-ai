## CU25. Consultar asistente empresarial inteligente

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU25. Consultar asistente empresarial inteligente |
| Propósito | Proporcionar asistencia en la consulta e interpretación de información operativa, financiera y administrativa del taller. |
| Resumen | El empleado interactúa con agentes inteligentes internos que consultan información autorizada y elaboran respuestas contextualizadas. |
| Actores | Administrador, Jefe de taller, Responsable financiero, Recepcionista. |
| Actor iniciador | Empleado autorizado. |
| Precondición | El usuario dispone de una sesión válida y permisos para acceder a la información solicitada. El servicio de agentes se encuentra disponible. |
| Flujo principal | **1.** El usuario accede al asistente empresarial. **2.** Introduce una consulta en lenguaje natural. **3.** El sistema identifica la intención de la solicitud. **4.** Selecciona las capacidades del agente interno apropiado. **5.** Valida los permisos del usuario para cada consulta. **6.** Recupera datos mediante las APIs empresariales autorizadas. **7.** El agente organiza e interpreta los resultados. **8.** Presenta una respuesta acompañada de indicadores, referencias internas o aclaraciones cuando corresponda. **9.** El usuario puede realizar una nueva consulta relacionada. |
| Postcondición | El usuario recibe asistencia basada en información permitida, sin alterar los datos del sistema. |
| Excepción | Solicitud ambigua; información inexistente; falta de permisos; fallo de conexión; servicio de agente no disponible; intento de ejecutar acciones no autorizadas; instrucciones maliciosas dentro de datos consultados. Las acciones que modifiquen registros requieren un caso de uso autorizado y confirmación explícita. |
