## CU12. Crear orden de trabajo

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU12. Crear orden de trabajo |
| Propósito | Formalizar una solicitud de mantenimiento o reparación automotriz mediante una orden que permita controlar su ejecución. |
| Resumen | La recepcionista o el jefe de taller registra una orden vinculada al vehículo, al cliente y a los servicios solicitados. |
| Actores | Recepcionista, Jefe de taller. |
| Actor iniciador | Recepcionista. |
| Precondición | El cliente y el vehículo están registrados, existe una recepción válida y el usuario está autorizado. |
| Flujo principal | **1.** El usuario accede a la recepción del vehículo. **2.** Selecciona crear orden de trabajo. **3.** El sistema recupera los datos del cliente y vehículo. **4.** El usuario selecciona uno o varios servicios del catálogo. **5.** Añade descripción del problema, prioridad y observaciones. **6.** El sistema valida la información. **7.** El usuario confirma la creación. **8.** El sistema genera un identificador único y guarda la orden con estado pendiente de cotización o autorización. |
| Postcondición | Se crea una orden de trabajo asociada al vehículo y lista para continuar el proceso de atención. |
| Excepción | Recepción inexistente; orden duplicada; servicio inactivo; información incompleta; falta de permisos; error de almacenamiento. Una orden creada offline queda provisional hasta que el servidor valide su registro. |
