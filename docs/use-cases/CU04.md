## CU04. Gestionar horarios y disponibilidad

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU04. Gestionar horarios y disponibilidad |
| Propósito | Organizar los turnos y la disponibilidad de los mecánicos para distribuir correctamente los servicios automotrices. |
| Resumen | El administrador o jefe de taller configura jornadas laborales, horarios, ausencias y disponibilidad de los empleados. |
| Actores | Administrador, Jefe de taller. |
| Actor iniciador | Administrador o Jefe de taller. |
| Precondición | Los empleados están registrados y activos. El usuario tiene permisos para administrar horarios. |
| Flujo principal | **1.** El usuario ingresa a planificación del personal. **2.** Selecciona un empleado o un grupo de empleados. **3.** Consulta el calendario de trabajo y los horarios registrados. **4.** Define jornadas, turnos, descansos o períodos de ausencia. **5.** El sistema revisa posibles conflictos con asignaciones existentes. **6.** El usuario confirma los cambios. **7.** El sistema guarda la planificación y actualiza la disponibilidad para futuras asignaciones. |
| Postcondición | Los horarios y la disponibilidad del personal quedan actualizados. |
| Excepción | Horarios superpuestos; empleado inactivo; turnos fuera de la jornada permitida; asignaciones previamente confirmadas; falta de permisos; error al guardar. Los cambios que afecten servicios confirmados requieren reasignación o autorización. |
