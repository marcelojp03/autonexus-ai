## CU19. Registrar cobro de servicio

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU19. Registrar cobro de servicio |
| Propósito | Registrar los pagos recibidos por los trabajos mecánicos realizados. |
| Resumen | El responsable financiero registra el importe cobrado, el método de pago y la orden de trabajo correspondiente. |
| Actores | Responsable financiero. |
| Actor iniciador | Responsable financiero. |
| Precondición | Existe una orden de trabajo con una obligación de pago válida y el usuario posee permisos de cobro. |
| Flujo principal | **1.** El responsable financiero accede a las órdenes pendientes de cobro. **2.** Selecciona una orden. **3.** El sistema muestra el importe acordado, pagos previos y saldo pendiente. **4.** El usuario selecciona el método de pago e introduce el importe recibido. **5.** El sistema valida que la operación sea consistente con el saldo y las condiciones del servicio. **6.** El usuario confirma la recepción del pago. **7.** El sistema registra el cobro y actualiza el saldo. **8.** Genera un comprobante interno y, cuando corresponda, integra el proceso de emisión fiscal aplicable. |
| Postcondición | El pago queda registrado, asociado con su orden y reflejado en los indicadores financieros. |
| Excepción | Orden inexistente; importe inválido; pago duplicado; referencia de pago no verificada; saldo inconsistente; error al registrar; falta de permisos. Los cobros no se confirman offline para evitar duplicidades. Las devoluciones o anulaciones requieren operaciones financieras auditadas, no eliminación del registro original. |
