## CU17. Verificar y finalizar orden de trabajo

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU17. Verificar y finalizar orden de trabajo |
| Propósito | Verificar que los servicios asignados hayan sido realizados satisfactoriamente antes de declarar finalizada una reparación. |
| Resumen | El jefe de taller revisa los trabajos registrados por los mecánicos, valida las evidencias y autoriza la finalización técnica de la orden. |
| Actores | Jefe de taller, Mecánico. |
| Actor iniciador | Jefe de taller. |
| Precondición | Existe una orden en ejecución y el mecánico ha registrado las actividades requeridas para su revisión. |
| Flujo principal | **1.** El jefe de taller consulta las órdenes pendientes de verificación. **2.** Selecciona una orden. **3.** Revisa los servicios programados y las actividades registradas. **4.** Consulta observaciones y evidencias disponibles. **5.** Verifica que no existan actividades obligatorias pendientes. **6.** Registra el resultado de la revisión. **7.** Autoriza la finalización técnica de la orden. **8.** El sistema actualiza su estado a finalizada, pendiente de entrega y, si corresponde, pendiente de cobro. |
| Postcondición | La orden queda técnicamente finalizada y disponible para las operaciones administrativas posteriores. |
| Excepción | Actividades incompletas; evidencia insuficiente; problemas detectados durante la revisión; falta de autorización; información desactualizada; error de persistencia. Si se rechaza la revisión, la orden regresa al estado de ejecución o corrección. |
