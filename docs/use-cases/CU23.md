## CU23. Analizar imágenes mediante IA del servidor

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU23. Analizar imágenes mediante IA del servidor |
| Propósito | Ejecutar análisis visuales más especializados mediante modelos de inteligencia artificial alojados en el servidor. |
| Resumen | El mecánico envía imágenes del vehículo para su procesamiento mediante el microservicio de inteligencia automotriz, desarrollado con Python, FastAPI y TensorFlow. |
| Actores | Mecánico, Jefe de taller, Amazon S3. |
| Actor iniciador | Mecánico. |
| Precondición | Existe conectividad, el usuario está autorizado y la imagen cumple con los requisitos de procesamiento. |
| Flujo principal | **1.** El mecánico accede al módulo de análisis inteligente. **2.** Selecciona una orden y una o varias imágenes. **3.** El sistema valida el formato, tamaño y autorización de los archivos. **4.** Las imágenes se cargan de manera segura en Amazon S3. **5.** El sistema envía al microservicio de IA una solicitud de análisis que contiene referencias autorizadas a las imágenes. **6.** El modelo TensorFlow procesa las imágenes y genera predicciones. **7.** El microservicio registra los resultados, las puntuaciones y metadatos del análisis en MongoDB. **8.** El sistema presenta los resultados al mecánico. **9.** El mecánico valida, corrige o descarta las observaciones y decide cuáles incorporar a la orden. |
| Postcondición | El análisis queda registrado con referencias a sus imágenes en S3 y resultados en MongoDB. |
| Excepción | Sin conexión; imagen inválida; fallo de carga a S3; error del modelo; servicio de IA no disponible; resultado inconcluso; procesamiento excedido; falta de permisos. Las inspecciones no deben convertirse automáticamente en diagnósticos definitivos. |
