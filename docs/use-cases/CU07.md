## CU07. Gestionar vehículos

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU07. Gestionar vehículos |
| Propósito | Registrar los vehículos atendidos por el taller y relacionarlos con sus respectivos clientes. |
| Resumen | La recepcionista administra información como placa, marca, modelo, año y características del vehículo. |
| Actores | Recepcionista, Administrador. |
| Actor iniciador | Recepcionista. |
| Precondición | Existe un cliente registrado y el usuario tiene permisos para administrar vehículos. |
| Flujo principal | **1.** La recepcionista ingresa al módulo de vehículos. **2.** Busca un vehículo mediante su placa o identificador. **3.** Selecciona registrar o modificar vehículo. **4.** Ingresa placa, marca, modelo, año, tipo de combustible y otros datos disponibles. **5.** Asocia el vehículo con su cliente. **6.** El sistema valida los datos y comprueba posibles duplicados. **7.** La recepcionista confirma la operación. **8.** El sistema guarda el registro y habilita su historial de servicios. |
| Postcondición | El vehículo queda registrado o actualizado y asociado con un cliente. |
| Excepción | Placa duplicada; cliente inexistente; información inválida; conflicto de asociación; falta de permisos; error al guardar. Los cambios de propietario deberán conservar trazabilidad histórica. |
