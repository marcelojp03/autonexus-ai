## CU31. Administrar acceso de clientes MCP externos

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU31. Administrar acceso de clientes MCP externos |
| Propósito | Controlar qué aplicaciones externas pueden conectarse mediante MCP y qué herramientas están autorizadas a utilizar. |
| Resumen | El administrador registra y configura aplicaciones externas, define sus permisos y puede suspender o revocar sus accesos. |
| Actores | Administrador. |
| Actor iniciador | Administrador. |
| Precondición | El administrador está autenticado y cuenta con privilegios para gestionar integraciones externas. |
| Flujo principal | **1.** El administrador abre la sección de integraciones MCP. **2.** Consulta los clientes autorizados. **3.** Selecciona registrar o modificar un cliente. **4.** Introduce los datos de identificación y configuración necesarios. **5.** Define los permisos, herramientas y alcances de acceso. **6.** El sistema valida la configuración y registra el cliente mediante el mecanismo de autorización correspondiente. **7.** El administrador confirma los cambios. **8.** El sistema actualiza los permisos efectivos y registra el evento en la auditoría. |
| Postcondición | El cliente MCP queda configurado con permisos explícitos, o su acceso queda suspendido o revocado según la acción realizada. |
| Excepción | Cliente duplicado; configuración inválida; permisos excesivos; credenciales comprometidas; falta de privilegios; error al actualizar autorizaciones. La revocación deberá impedir nuevas operaciones autorizadas, respetando el funcionamiento del mecanismo de autenticación y sus políticas de vigencia. |
