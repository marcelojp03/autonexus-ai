## CU21. Consultar indicadores empresariales

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU21. Consultar indicadores empresariales |
| Propósito | Facilitar la evaluación del desempeño operativo y financiero del taller. |
| Resumen | El administrador consulta indicadores sobre servicios realizados, ingresos, gastos, productividad y tiempos de reparación mediante un panel empresarial. |
| Actores | Administrador, Jefe de taller, Responsable financiero. |
| Actor iniciador | Administrador. |
| Precondición | El usuario dispone de permisos para consultar los indicadores solicitados. Existen datos registrados en los módulos correspondientes. |
| Flujo principal | **1.** El administrador abre el panel de indicadores. **2.** Selecciona el período y los filtros de análisis. **3.** El microfrontend realiza una consulta GraphQL. **4.** El BFF obtiene los datos autorizados de los microservicios de Operaciones, Empleados y Finanzas. **5.** El sistema calcula o recupera los indicadores definidos. **6.** Presenta gráficos, tablas y estadísticas. **7.** El usuario examina los resultados y modifica los filtros según sus necesidades. |
| Postcondición | El usuario obtiene una vista consolidada del rendimiento empresarial sin modificar los datos de origen. |
| Excepción | Información insuficiente; ausencia de datos para el período; falta de permisos; fallo parcial de un microservicio; respuesta GraphQL inválida; datos desactualizados. Los indicadores afectados deben mostrarse como no disponibles o parciales, sin inventar resultados. |
