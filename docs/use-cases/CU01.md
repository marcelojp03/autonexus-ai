## CU01. Iniciar sesión

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU01. Iniciar sesión |
| Propósito | Autenticar de manera segura a los empleados y permitirles acceder a las funcionalidades correspondientes a sus permisos mediante inicio de sesión único. |
| Resumen | El empleado accede a AutoNexus AI utilizando un mecanismo de autenticación centralizado con Keycloak. |
| Actores | Administrador, Recepcionista, Mecánico, Jefe de taller, Responsable financiero, Keycloak. |
| Actor iniciador | Empleado del taller. |
| Precondición | El empleado tiene una cuenta registrada y activa. Para la primera autenticación debe existir conectividad con Keycloak. |
| Flujo principal | **1.** El empleado abre la plataforma web o móvil. **2.** Selecciona la opción de iniciar sesión. **3.** El sistema lo redirige al mecanismo de autenticación de Keycloak. **4.** El empleado proporciona sus credenciales. **5.** Keycloak verifica su identidad. **6.** La plataforma valida la sesión y obtiene los permisos correspondientes. **7.** El sistema muestra los módulos autorizados para el empleado. |
| Postcondición | El empleado cuenta con una sesión válida y puede acceder a las funcionalidades autorizadas. |
| Excepción | Credenciales incorrectas; cuenta deshabilitada; sesión expirada; error de comunicación con Keycloak; permisos insuficientes. En modo offline solo se permite acceso local previamente habilitado, con credenciales y permisos almacenados de manera segura y dentro de su vigencia. |
