## CU24. Estimar duración de servicios mediante Machine Learning

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU24. Estimar duración de servicios mediante Machine Learning |
| Propósito | Apoyar la planificación del taller mediante estimaciones de tiempo de ejecución basadas en información histórica. |
| Resumen | El jefe de taller solicita una estimación del tiempo necesario para ejecutar un servicio, considerando trabajos anteriores y características relevantes. |
| Actores | Jefe de taller, Administrador. |
| Actor iniciador | Jefe de taller. |
| Precondición | Existe un servicio definido y una orden o solicitud válida. Para utilizar ML debe existir un modelo entrenado y evaluado con datos suficientes. |
| Flujo principal | **1.** El jefe de taller selecciona una orden de trabajo. **2.** Solicita estimar la duración del servicio. **3.** El sistema obtiene información sobre el servicio, vehículo y datos históricos permitidos. **4.** Prepara las variables requeridas por el modelo. **5.** Ejecuta el modelo de machine learning cuando existe uno validado. **6.** Obtiene una estimación de duración y, cuando corresponde, un intervalo de incertidumbre. **7.** Presenta el resultado junto con la fuente de estimación utilizada. **8.** El jefe de taller acepta o ajusta manualmente el tiempo previsto. **9.** El sistema registra la estimación seleccionada para la planificación. |
| Postcondición | La orden dispone de una duración estimada, identificada como predicción del modelo o estimación manual. |
| Excepción | Datos históricos insuficientes; modelo no disponible; variables incompletas; resultado fuera de límites razonables; servicio no reconocido. En estos casos se utiliza la duración referencial del catálogo y se informa que no es una predicción ML validada. |
