## CU03. Gestionar empleados

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU03. Gestionar empleados |
| Propósito | Registrar y mantener actualizada la información del personal que trabaja en el taller mecánico. |
| Resumen | El administrador gestiona los datos personales y laborales de los empleados, incluyendo sus cargos, especialidades y estado laboral. |
| Actores | Administrador, Keycloak. |
| Actor iniciador | Administrador. |
| Precondición | El administrador ha iniciado sesión y posee permisos de administración de personal. |
| Flujo principal | **1.** El administrador ingresa al módulo de empleados. **2.** Consulta la lista de empleados registrados. **3.** Selecciona registrar o modificar un empleado. **4.** Ingresa nombres, datos de contacto, cargo, especialidad y estado laboral. **5.** El sistema verifica los campos obligatorios y posibles duplicados. **6.** El administrador confirma la operación. **7.** El sistema guarda los datos laborales en el microservicio de empleados. **8.** Cuando corresponde, crea o actualiza la cuenta vinculada en Keycloak. |
| Postcondición | La información del empleado queda registrada o actualizada. |
| Excepción | Información incompleta; empleado duplicado; datos inválidos; falta de permisos; error de persistencia; imposibilidad de crear la cuenta de acceso. Un empleado con historial de trabajo no se elimina físicamente: se desactiva conservando sus registros históricos. |
