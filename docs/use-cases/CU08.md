## CU08. Consultar historial de servicios de un vehículo

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU08. Consultar historial de servicios de un vehículo |
| Propósito | Recuperar las atenciones anteriores de un vehículo para facilitar su seguimiento y futuras inspecciones. |
| Resumen | Los empleados autorizados consultan las órdenes de trabajo, servicios realizados, observaciones y evidencias del historial automotriz. |
| Actores | Recepcionista, Mecánico, Jefe de taller, Administrador. |
| Actor iniciador | Recepcionista, Mecánico o Jefe de taller. |
| Precondición | El vehículo está registrado y el usuario posee permisos para consultar su información. |
| Flujo principal | **1.** El usuario accede a la ficha del vehículo. **2.** Selecciona consultar historial. **3.** El sistema recupera las órdenes y los servicios registrados. **4.** Presenta fechas, tipos de servicio, estados y observaciones. **5.** El usuario selecciona una intervención anterior. **6.** El sistema muestra detalles, diagnósticos y evidencias autorizadas. **7.** Si existen fotografías, recupera su acceso seguro desde Amazon S3. |
| Postcondición | El historial es consultado sin modificar sus registros. |
| Excepción | Historial vacío; vehículo inexistente; permiso insuficiente; archivo no disponible en S3; pérdida de conectividad. En modo offline solo se mostrarán los registros y evidencias descargados previamente. |
