## CU06. Gestionar clientes

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU06. Gestionar clientes |
| Propósito | Administrar la información de las personas que solicitan servicios automotrices al taller. |
| Resumen | La recepcionista registra, consulta y actualiza los datos de los clientes. |
| Actores | Recepcionista, Administrador. |
| Actor iniciador | Recepcionista. |
| Precondición | El usuario está autenticado y cuenta con permisos para administrar clientes. |
| Flujo principal | **1.** La recepcionista abre el módulo de clientes. **2.** Busca al cliente por nombre, documento o teléfono. **3.** Si no existe, selecciona registrar cliente. **4.** Ingresa nombres, documento, teléfono, correo y dirección, según los datos necesarios. **5.** El sistema valida la información y verifica posibles duplicados. **6.** La recepcionista confirma los datos. **7.** El sistema registra el cliente y lo habilita para vincular vehículos y servicios. |
| Postcondición | El cliente queda registrado o actualizado. |
| Excepción | Datos obligatorios ausentes; documento duplicado; formato inválido; falta de permisos; error de conexión o persistencia. Si el registro se realiza offline queda pendiente de sincronización y verificación de duplicados. |
