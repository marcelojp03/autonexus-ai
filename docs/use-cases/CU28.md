## CU28. Ejecutar automatizaciones empresariales

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU28. Ejecutar automatizaciones empresariales |
| Propósito | Automatizar tareas administrativas repetitivas mediante eventos empresariales y flujos configurados en n8n. |
| Resumen | La plataforma emite eventos cuando ocurren determinadas operaciones, y n8n ejecuta las acciones automatizadas correspondientes. |
| Actores | Administrador, n8n. |
| Actor iniciador | Administrador al configurar el flujo; posteriormente, n8n o un evento empresarial autorizado inicia cada ejecución. |
| Precondición | Existe un flujo configurado y habilitado en n8n, con credenciales limitadas y un evento o programación válida. |
| Flujo principal | **1.** El administrador habilita una automatización definida. **2.** La plataforma registra un evento empresarial, como una orden finalizada o una cita próxima. **3.** El sistema publica el evento mediante el mecanismo de integración correspondiente. **4.** n8n recibe el evento autenticado o se activa mediante una programación. **5.** Comprueba las condiciones configuradas. **6.** Ejecuta las acciones autorizadas, como preparar un recordatorio o solicitar un reporte. **7.** Registra el resultado de ejecución. **8.** El sistema conserva el estado para seguimiento y auditoría. |
| Postcondición | La automatización se ejecuta y queda registrado su resultado. |
| Excepción | Flujo deshabilitado; credenciales inválidas; evento duplicado; servicio externo no disponible; error de ejecución; destinatario inexistente; falta de permisos. Se permiten reintentos controlados para operaciones idempotentes. Las fallas de automatización no deben revertir una reparación ya confirmada. |
