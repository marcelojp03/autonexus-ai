## CU29. Consultar información mediante MCP

| Campo | Detalle |
| --- | --- |
| Nombre de CU | CU29. Consultar información mediante MCP |
| Propósito | Permitir que aplicaciones externas de inteligencia artificial compatibles con MCP consulten información autorizada de AutoNexus AI mediante una interfaz estandarizada. |
| Resumen | Un cliente MCP externo se conecta al servidor MCP de AutoNexus AI y utiliza herramientas de consulta previamente habilitadas. |
| Actores | Aplicación de IA externa compatible con MCP. |
| Actor iniciador | Aplicación de IA externa compatible con MCP. |
| Precondición | El cliente MCP está registrado o autorizado mediante el mecanismo de autenticación definido. El servicio MCP está disponible y el cliente cuenta con los permisos necesarios. |
| Flujo principal | **1.** La aplicación externa establece una conexión con el servidor MCP. **2.** Se realiza la autenticación y negociación de capacidades del protocolo. **3.** El cliente descubre las herramientas y recursos disponibles según su autorización. **4.** Selecciona una herramienta, por ejemplo `consultar_historial_vehiculo` o `listar_servicios`. **5.** El servidor MCP valida los argumentos y los permisos del cliente y, cuando corresponda, del usuario delegado. **6.** Invoca las APIs internas autorizadas de AutoNexus AI. **7.** Recibe la información permitida. **8.** Devuelve una respuesta estructurada al cliente MCP. **9.** Registra la operación para auditoría. |
| Postcondición | El cliente MCP obtiene la información autorizada sin acceder directamente a las bases de datos de la plataforma. |
| Excepción | Cliente no autorizado; credenciales expiradas; herramienta inexistente; argumentos inválidos; falta de permisos; datos sensibles no autorizados; fallo de comunicación; límites de uso excedidos. |
